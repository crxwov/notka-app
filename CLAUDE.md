# Нотка: инструкции Claude

В проекте два разработчика: **leksik** — автор первоначальной Нотки; **crxwov (hackov / Егор)** — второй разработчик, подключился позже и помогает с приложениями, инфраструктурой и развитием.

Обязательные общие правила: [AGENTS.MD](AGENTS.MD) и [сотрудничество](docs/operations/collaboration.md). Перед задачей читать актуальные origin/main: [todo.md](todo.md), [работу leksik](already-work-leksik.md), [работу crxwov](already-work-crxwov.md). Не создавать новые Roadmap и отдельные файлы памяти задач.

Подробное состояние своей текущей работы публиковать в своём already-work-файле до правок, примерно раз в 60 секунд во время работы и после смены состояния. При пересечении с чужой активной/неизвестной/устаревшей работой предупредить пользователя и не править пересекающуюся область до разрешения конфликта. Не переписывать файл другого участника.

Для Claude leksik использовать participant=leksik только когда задача действительно поручена leksik. Агент crxwov использует свой файл независимо от выбранной рабочей ветки. Команда публикации/heartbeat, ограничения и правила Git — в collaboration.md.

Технические решения принимать самостоятельно в согласованной области; вопросы задавать при необходимых продуктовых решениях/конфликтах. Беречь чужую незакоммиченную работу. Push не означает деплой.

Дизайн, все сохранённые правила 3D-иконок/материалов/света: [DESIGN.md](DESIGN.md). Продукт: [PRODUCT.md](PRODUCT.md). Исходники: [PROJECT_INDEX.md](PROJECT_INDEX.md). Инфраструктура: [проверенный срез](docs/operations/infrastructure-2026-10-14.md).
