# Устройство Telegram-бота (`bot/`)

[← Нотка Плюс и ивенты](../services/plus-and-events.md) · [К оглавлению](../README.md) · [Далее: Экраны и модалки Mini App →](../miniapp/screens-and-modals.md)

---

Telegram-бот написан на `aiogram 3.13` и состоит из двух файлов:
- `bot/config.py` — загрузка `BOT_TOKEN` и `MINIAPP_URL` в dataclass `BotSettings`.
- `bot/main.py` — точка входа поллинга и обработчики команд.

## 1. Инициализация при запуске (`on_startup`)

При старте поллинга функция `on_startup(bot)` устанавливает глобальную кнопку меню чата:
```python
MenuButtonWebApp(text="Нотка", web_app=WebAppInfo(url=settings.miniapp_url))
```
Благодаря этому у каждого пользователя рядом с полем ввода сообщения всегда доступна кнопка **«Нотка»**, открывающая мини-приложение в один тап.

---

## 2. Команда `/start` и обработка Deep Links (`handle_start`)

Хэндлер `/start [payload]` поддерживает 3 режима работы в зависимости от переданного параметра `payload`:

### Режим А: Активация промокода (`/start promo_<CODE>`)
Когда пользователь переходит по ссылке вида `https://t.me/<bot>?start=promo_NOTKA30`:
- Бот нормализует код (`NOTKA30`), формирует URL `${MINIAPP_URL}?promo=NOTKA30` и отправляет сообщение с inline-кнопкой WebApp **«🎁 Активировать Плюс»**.
- При нажатии открывается Mini App, которое автоматически считывает `?promo=NOTKA30` и активирует подписку через `POST /plus/redeem`.

### Режим Б: Открытие общего трека или плейлиста (`/start t_...` или `/start p_...`)
Когда друг делится треком или плейлистом из приложения:
- **Ссылка на трек**: `https://t.me/<bot>?start=t_youtube_music_dQw4w9WgXcQ` $\rightarrow$ бот присылает кнопку WebApp **«▶ Слушать»** с параметром `?t=...`.
- **Ссылка на плейлист**: `https://t.me/<bot>?start=p_AbC123xYz` $\rightarrow$ бот присылает кнопку WebApp **«▶ Открыть плейлист»** с параметром `?p=...`.

### Режим В: Обычный запуск (`/start`)
- Бот сначала отправляет и тут же удаляет сервисное сообщение с `ReplyKeyboardRemove()`, чтобы очистить у старых пользователей устаревшую нижнюю клавиатуру.
- Затем отправляет приветственное сообщение с inline-кнопкой WebApp **«🔥 Открыть Нотку»**.

## 3. Команда `/id` (`handle_id`)

Возвращает пользователю его числовой Telegram ID:
```text
Твой Telegram ID: 123456789
Добавь его в .env как ADMIN_IDS=123456789 чтобы управлять промокодами.
```

---

## 4. Администрирование промокодов `/promo` (`handle_promo`)

Доступна только пользователям, чей Telegram ID перечислен в переменной `ADMIN_IDS` в `.env`:

| Команда в чате с ботом | Действие |
| :--- | :--- |
| `/promo` | Показывает список всех существующих промокодов из `data/plus.json`: статус (`🟢` / `🔴`), сколько дней даёт, счётчик активаций `used/max_uses` и готовую ссылку `https://t.me/<bot>?start=promo_<КОД>`. |
| `/promo <КОД> <ДНЕЙ> <ЛИМИТ> [СРОК_ДНЕЙ]` | Создаёт новый промокод через `plus_store.create_promo()`.<br>Пример: `/promo VIBE30 30 50 14` — создаст код `VIBE30` на 30 дней Плюса для 50 человек со сроком действия 14 дней. |
| `/promo off <КОД>` | Мгновенно отключает промокод через `plus_store.disable_promo(code)`. |
