# Серверные правки Нотки

`telegram-avatar.patch` хранит выложенные изменения API и Mini App для загрузки аватара Telegram в Windows-клиенте. Патч предназначен для серверного дерева с `music_resolver/` и `miniapp/`. Перед применением к актуальному дереву проверьте контекст и версию `app.js`. Рабочий сервер уже содержит эти изменения.
